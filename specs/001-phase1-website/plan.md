# Implementation Plan: Phase 1 - Embroidery Digitizing Business Website

**Branch**: `001-phase1-website` | **Date**: 2025-12-30 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/001-phase1-website/spec.md`

---

## Summary

Build a professional, conversion-focused marketing website for EMB Digitizers (embdigitizers.com) using Next.js 14+ App Router with TypeScript and Tailwind CSS. Phase 1 delivers 6 core pages (Home, Services, Pricing, About, Contact, FAQ) with static content, a functional contact form, and mobile-responsive design. No authentication, payments, or order uploads in this phase.

---

## Technical Context

**Language/Version**: TypeScript 5.x, Node.js 18+
**Primary Dependencies**: Next.js 14+, React 18+, Tailwind CSS 3.4+, Zod, React Hook Form
**Storage**: N/A (static data, email via API service)
**Testing**: Vitest, Testing Library, Playwright (E2E)
**Target Platform**: Web (modern browsers: Chrome, Firefox, Safari, Edge)
**Project Type**: Web Application (Next.js App Router)
**Performance Goals**: LCP < 2.5s, FID < 100ms, CLS < 0.1, Lighthouse 90+
**Constraints**: < 3s page load, mobile-first, WCAG 2.1 AA accessibility
**Scale/Scope**: 6 pages, ~20 components, single contact form

## Architecture Overview

### Component Hierarchy

```
RootLayout
├── Navbar (all pages)
│   ├── Logo
│   ├── NavLinks
│   └── MobileMenu (client component)
├── Main Content (per page)
│   └── [Page-specific sections]
└── Footer (all pages)
```

### Data Flow

```
Static Data (/lib/data/)
    ↓
Server Components (pages)
    ↓
UI Components (render props)
    ↓
Browser (HTML + minimal JS)
```

### Form Submission Flow

```
ContactForm (Client Component)
    ↓ validate (client)
Server Action (contact.ts)
    ↓ validate (server)
Email Service (Resend/SendGrid)
    ↓
Business Email
```

## Component Specifications

### UI Components (Atoms)

| Component | Props | Styling Notes |
| --------- | ----- | ------------- |
| Button | variant, size, href, disabled, loading | Primary: blue bg, Secondary: outline |
| Badge | children, variant | Small text with background |
| Icon | name, size | SVG icon system or lucide-react |
| Accordion | items, allowMultiple | Animated expand/collapse |

### Layout Components

| Component | Props | Notes |
| --------- | ----- | ----- |
| Navbar | - | Server component, logo + nav links |
| MobileMenu | isOpen, onClose | Client component with animation |
| Footer | - | Contact info + quick links |
| Container | size, className | Max-width wrapper (max-w-7xl) |
| PageHero | title, subtitle | Page header section |

### Card Components

| Component | Props | Reuse |
| --------- | ----- | ----- |
| ServiceCard | service, variant | Home, Services |
| PricingCard | tier | Pricing |
| TestimonialCard | testimonial | Home |
| MetricCard | label, value, icon | About, Home |
| ValueCard | title, description, icon | Home, About |

### Section Components

| Component | Props | Page |
| --------- | ----- | ---- |
| Hero | headline, subheadline, cta | Home |
| TrustBar | signals | Home |

| PricingGrid | tiers | Pricing |
